# v49 —— 第一项「游戏里本来没有」的科技出现在研究卡上（2026-10-22 实机）

## 这是什么

`tech.create` 的屏幕链路第一次被玩家确认。在此之前它只被证明到「`.dat` 里多了一条记录、重解析读得回、字符串表有名字」——
这三件事都不能说明引擎会把它画在卡上、更不能说明它能被研究。

## 构建

```
_probe\tmp_build_v49.py
  intents = [ unit.stat 109 British hit_points 4000,
              tech.create donor=22(织布机) name=铁匠学徒的手艺 building=109(城镇中心)
                          research_time=10 button=8 ]
  build_bundle -> _probe\out_v49\  (dat_raw 93,268,234 B, +82 over shipped, edit_count 316)
  install      -> local//dsh test v49 新建科技上卡, enabled, priority 3
```

`.dat` 里那一条（从已装的 mod 上重读，不信 manifest）：

```
tech 1510  name=NewTech1510  lang_name=30030002  effect_id=22
           locations=[(109, 10, 8)]      # 城镇中心，第 8 格，研究 10 秒
zh/en 两张 key-value-modded 表各 1 个头、各定义 30030002
```

## 读数（用户实机，三答合一）

> 用户选择：「三处都对（有新手艺、城镇中心 4840、研究完卡上出现新科技）」
>
> 随后用户纠正（m45262）：「城镇中心血量是4000」。
> 选项文案里的 4840 是我预先写的推算值（帝王时代加成 2400×1.21），真实读数是原值 4000。两个数字都说明「已挂载」（出厂 2904 才是未挂载），但实测录的是 4000。

| 检查点 | 读数 | 它证明了什么 |
|---|---|---|
| 城镇中心血量 | **4000/4000** —— 用户原话：「城镇中心血量是4000」 | mod 真的被加载了；出厂 2400 × 1.21（帝王时代加成）= 2904，所以数字不是 2904 = 已挂载 |
| 研究卡第 8 格 | **出现了「铁匠学徒的手艺」** | 引擎**接受 index 1510**，并且接受一条**追加出来的**研究位置 |
| 研究之后 | 该项科技在卡上、可研究 | `effect_id=22`（照抄织布机的 effect）跟着新记录生效 |

## 它结掉了哪两条 `not_proven`

`aoe2mod/api.py` 的 `_build_new_tech` 之前写了两条「没有证过」：

1. ~~运行中的游戏会不会画这个图标~~ —— 会。它借用捐赠者的图标（这里就是织布机的图标），
   因为 `icons.json` 的 `Units` 段 0..999 全占满、`Techs` 段 0..312 全占满，这个工具不改图标那层。
2. ~~引擎是否可达 index 1510~~ —— **可达**。出货科技树已引用 517 个 >1,509 的 Node ID，那是鼓励；
   这一局是证明。

## 它没有结掉什么

- **科技树面板上仍然没有它**：科技的 Node ID 与单位共用一套整数，1510 在科技树里已经是单位
  `City Gate NE (Rubble)`。这项新科技只有 `.dat` 那一半 —— 能被研究，但不在科技树里。
- **同一格挤**：第 8 格本来就有城镇瞭望(8) 与城镇巡逻(280)。出厂数据里 66 对 `(建筑, 格子)`
  已经被两项以上科技共用，所以这不是冲突，是既有做法；预览现在会点名那几项。
- **成本**：照抄捐赠者。写不了（成本槽是逐字节重放的），也没有让玩家改。

## 为什么这次结果可信（而不是又一次「看起来像」）

三次踩过的坑，这次都避开了：

1. **canary**：同一个 mod 里有 2400→4000 的城镇中心血量，读数 **4000** 是「加载了」的独立证据（出厂值 2904）。
   没有 canary 的那几轮（v41 等）空结果与没加载不可区分。
2. **场景模组**：`[Map]7V1_The_ThreeKingdoms` 会伪造开局（20000 资源 / 帝王时代 / 自带骑兵），
   已 `Enabled=False`，所以这一局是标准局。
3. **美术模组**：`182654_Age of Anime (Chibi Edition)` 把单位外观全换皮，所以判断一律不靠「看起来像」，
   靠面板文字与血量数字。
