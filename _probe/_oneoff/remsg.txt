Rebuild puts the rebuilt mod back where it lives

`/api/rebuild` exists to fix a mod that went stale after a game update. It
answered `ok: true` with a fresh `edit_count` while the installed file kept its
old bytes, and a second test showed why: `replay` never passed `install`, so the
build landed in a temp folder, and it built under `"<stat> <unit>"` instead of the
record's title, so even an install would have created a second folder beside the
stale one.

Measured on the shipped binary: build a scoped mod, overwrite its .dat with junk,
rebuild -- the file still hashed as junk. Now it comes back byte-identical to the
first build, still scoped to the civilization the sentence named.

`_probe/test_rebuild_installs.py` asserts this against the file rather than the
response, and is in the suite.
