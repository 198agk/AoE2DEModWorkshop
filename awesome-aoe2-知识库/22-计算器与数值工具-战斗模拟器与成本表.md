## 0 一句话结论
这一节里真正有数据的只有两家：**aoe-combatsim.com**（144 个单位的完整战斗参数，藏在 1.58 MB 的 Angular bundle 里）与 **grishrl.github.io**（单位成本+训练时间表，数据自述来自 fandom、最后更新 2021-05-18）。其余计算器要么把数据写死在 HTML 里（villagers-required，2.6 MB 单页）、要么只有公式没有数据（gbts 明确"不支持 DE"）。

## 1 aoe-combatsim.com —— 144 个单位的战斗参数

站点是 Angular 打包（`main-es2015.ab7b004b81cd063ea50a.js`，1,577,146 B），单位不是 JSON 而是构造函数调用：
```js
e.ut_archer=new Rd("Archer",e.feudalAge,30,2,4,.35,7,.96,0,25,45,.2,0,80)
```
构造签名（从 `class Rd` 反解）：
```js
constructor(name, age, hp, attackSpeed, range, attackDelay, projectileSpeed, moveSpeed,
            costFood, costWood, costGold, radius=0.2, minRange=0, accuracyPercent=100, hpRegPerMin=0)
```
- `attackSpeed` = 攻击间隔（秒）；`attackDelay` = 起手延迟；`projectileSpeed`；`moveSpeed` = 格/秒。
- 攻击/护甲不是标量而是 Map：`ut_archer.attackValues.set(ac_spearman,3)` 表示"对 spearman 类 +3"。
- 共 **144 个单位**，其中 78 个带 HP、100 个带 baseMelee 攻击值、48 个带 basePierce 攻击值。
- 攻击/护甲 class 共 18 种：baseMelee 100、basePierce 48、eagleWarrior 39、spearman 24、cavalry 18、camel 16、ram 16、siegeWeapon 13、infantry 13、warElephant 11、mameluke 9、archer 9 …
