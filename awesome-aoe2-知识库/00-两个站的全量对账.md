### 1.4 原版漏掉的唯一实质内容：`bugs/Fixed.md`

2,165 B。内容是三条**已修复但会咬人**的坑：

1. `xsEffectAmount(cSetAttribute, 1071, cAmountFirstStorage, current_pop - 250, 8)` —— 第 5 个参数写 8 但**对局不足 8 人时直接崩**。要先用 `xsGetPlayerCount()` 之类判断，或对每个存活玩家单独算。
2. `xsEffectAmount(cEnableObject, -1, cEnableObject, 0)` —— **传负数 object/tech ID 崩**。动态算出来的 ID 必须先 `if (id >= 0)`。
3. **XS 脚本在联机大厅不传输**：host 自己跑得起来，其他人报 `failed to open file`。`#includeXS` 对 host 个人目录里的脚本有效，但**递归 include 和其他来源的脚本不传**。

→ 已并入 **08 卷**「bug 分类：Fixed（已修复但仍需知道）」，2,167 字符。

## 二、airef.github.io

### 2.1 这个站的性质

纯静态壳：**`tables/*` 六个页面全是空的**——HTML 里只有一个 `<script src="../js/commands.js">` 加 jQuery，表格用 JS 循环现拼。用浏览器爬永远拿不到表。

真数据在 **`js/commands.js`，2,023,772 B / 56,727 行**，全部是 `var cBuild = new Command("build","Action","AoC")` 这种构造语句。用 node `vm.runInContext` 执行后导出 **115 个数组**（`_probe/_tmp/airef_flat.json`，2.52 MB）。

### 2.2 一个必须纠正的误读

`tables/objects-bfg.html`、`tables/techs-bfg.html` 里的 **`bfg` 不是 Star Wars Galactic Battlegrounds**，是 **Chronicles: Battle for Greece（编年史：为希腊而战 DLC）**。页面原文：

> This list of objects in the Chronicles: Battle for Greece DLC doesn't include any Gaia objects… The only difference is the new Mouflon huntable animal unit (ID 2340).

对应数组后缀是 `Chr`。`ROR` = Return of Rome（罗马归来）。

## 三、一句话结论

- **ugc.aoe2.rocks**：51 个 URL 里 **41 个有正文、10 个源文件 0 字节**。有正文的全部进卷（288 函数 / 1170 常量 / 210 属性 / 601 资源 / 48 任务 / 134 效果 / 37 条件）；空的那 10 个已在卷内列明，**不是漏抓**。
- **airef.github.io**：六个 `tables/*` 全是 JS 空壳，数据从 `commands.js` 反解。**三套平行表（AoE2 / 编年史 / 罗马归来）现在都在 04 卷里**，加上 430 个 load-if 符号、SN 编号策略、赛事与资源索引、84 条 bug。

两站都已做到「站点有内容的，卷里全有；站点没内容的，卷里明说是空的」。
