## 0 一句话结论

这是**全网最大的 AoE2 模组索引**：61832 个 mod，但站点本身只是个"搜索+下载"前端——
真正的文件托管在 `cdn.ageofempires.com`，目录页只是把游戏内 mod 系统爬下来重建了一遍。
对模组开发的真正价值不是"下载别人的 mod"，而是**知道社区在做什么**：
`Data Mod` 9110 个、`User Interface` 5297 个、`Graphics` 1840 个、`Random Maps` 1457 个、`Artificial Intelligence` 990 个——
这几个数字直接告诉你"哪类模组的竞争最激烈、哪类是空白"。


## 1 API 逆向（这是本卷最有复用价值的部分）

首页 HTML 是 412 字节的 Svelte 壳，`/build/bundle.js`（49,085 B）里写死了两个端点。

### 1.1 列表接口

```http

POST https://mods.aoe2.se/api/v1/mods

Content-Type: application/json


{"page": 0, "modCategories": []}

```

返回：

```json
{ "modEntries": [ {...50 条...} ], "total": 61832, "filtered": 61832, "page": 0, "pageSize": 50 }
```

**逆向出来的行为**（全部实测）：

| 现象 | 实测结果 |
|---|---|
| `pageSize` / `size` / `limit` / `count` / `perPage` | **全部被忽略**，恒定 50 条/页 |
| 总页数 | `ceil(total/50)` = 1237 页 |
| `page` 上限 | 1236 之后返回 500 / 连接被断 |
| `GET /api/v1/mods` | 405 Method Not Allowed |
| `sortColumn` | 必须是枚举 `createDate` / `lastUpdate`，否则 422 |
| `sortDirection` | 必须是 `ASC` / `DESC`（**大写**），小写报 `value is not a valid enumeration member` |
| `searchTerm` | 支持，做名称模糊匹配 |
| `modCategories` | 按分类过滤，取值见 §1.3 |
| `civbuilder` | 布尔，true 只返回 civbuilder 生成的 mod |

**坑：本机的本地代理会掐掉长连接的深分页请求。**
深页（page > 400）用 `requests` 默认走系统代理时会大面积抛 `ProxyError: Remote end closed connection`；
加 `S.trust_env=False` 直连后全部 200。这是本机环境特性，不是站点限流——但也别开 10 线程以上（16/24 线程会拿到 0 字节响应）。

### 1.2 详情接口

```http
GET https://mods.aoe2.se/api/v1/mod/2359
```

返回 `{"modEntries":[{modId, modName, modTypeId, createDate, lastUpdate, json_str, fileList, civbuilder}]}`（约 17 KB）。
`json_str` 是**内嵌的 JSON 字符串**（不是对象），要二次 `json.loads`。`fileList` 是文件清单。

### 1.3 条目字段全解（`json_str` 里的 60+ 个键）

| 字段 | 含义 |
|---|---|
| `modId` | mod 唯一 ID，等于游戏内 mod 详情页 `ageofempires.com/mods/details/<id>` 的 id |
| `modName` | 名称 |
| `description / modDescription / changeList` | 简介 / 详细说明 / 更新日志 |
| `modVersion / verifiedVersion` | 版本号 / 已验证兼容的游戏版本 |
| `modTypeId / modType` | **恒为 1 / "Scenario"**——这是游戏内部的"包类型"，不是分类 |
| `modTagNames / modTagIds / modTags` | **真实分类在这里**（Data Mod、Graphics、Random Maps…） |
| `metaData` | 附加元信息 JSON 串 |
| `modStatusId / modStatus / modStatusMessage` | 审核状态 |
| `modVisibility` | 可见性 |
| `creatorId / creatorName / creatorAvatarUrl` | 作者 |
| `createDate / lastUpdate / updateAvailable` | 创建 / 更新 / 是否有新版 |
| `modFileSize / modDiskSize` | 压缩包大小 / 解压后占用 |
| `popular / thirtyDayPopular` | 历史热度 / 近 30 天热度 |
| `downloads / installs / likes` | 下载数 / 安装数 / 点赞 |
| `ratings{rating{average,totalCount}, reviewsCount}` | 评分 |
| `currentRating / positiveRatings / totalRatings` | 当前评分与正负评价数 |
| `thumbnail / imageUrls[{imageId,displayIndex,imageName,imageThumbnail}]` | 缩略图与截图 |
| `fileUrl` | **真实下载地址**（指向 cdn.ageofempires.com 的 zip） |
| `discourseUrl` | 讨论帖 |
| `sortName` | 排序用名 |

> **最大的认知陷阱**：`modType` 字段永远是 `"Scenario"`。用 `modType` 统计分类会得到一个假结论（"100% 都是场景"）。
必须用 `modTagNames`。

## 9 怎么用这个目录

1. **找同类参考**：想做一个 Data Mod，先按 `Data Mod` 标签 + 下载量排序，把头部几个的作者/体积/更新频率摸清，就知道这个赛道的门槛。
